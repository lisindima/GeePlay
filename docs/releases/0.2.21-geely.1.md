# GeePlay 0.2.21-geely.1

Independent, uncertified community project for Geely/ECARX head units. This project is not endorsed or certified by Apple, Geely or ECARX.

This is a pre-release based on DiPlay's 0.2.21 pre-release. The authenticated APK is an Android release build, not a debug APK. Hardware validation of this merged build is still pending.

- Synchronizes the common CarPlay stack through DiPlay `9d89633035d1add5b044ba3de5e57dd078bf2511` (0.2.21) and GeePlay main `d9881b4ae6b21ab12db1cc4f0f7d3a0857c3f09c`.
- Receives USB startup watchdog/recovery, wireless connection diagnostics, microphone recovery, call routing, media clock correction and wired/wireless buffer settings.
- Preserves `:geely`, `:vehicle-geely`, ECARX DIM, EVCC, Geely Navigation, iAP2 source ownership and Geely low-latency audio choices.
- Keeps BYD/DiLink settings and excluded AutoDisplay/MapEmbed/Telecom components outside the GeePlay product interface.
- Uses this fork's release feed and adds APK identity, signing-certificate, native Opus and credential checks before publication.

## Compatibility

G636 compatibility is documented by previous real-car validation in this repository. This new merged build requires a new real-car check; a successful build does not establish vehicle compatibility. G426 / Cityray remains experimental. Wired and wireless CarPlay both require compatible hardware/firmware and valid authentication.

## Authentication and signing

A diagnostic pre-release contains **no CarPlay authentication assets** and cannot be presented as a ready-to-use CarPlay release. It uses the separate `com.lllhys.geeplay.debug` package. A locally generated debug key does not establish continuity with earlier installations.

A full release may only be published with authorized authentication assets and the permanent release signing identity. Release package: `com.lllhys.geeplay`; versionCode: `5`. Only an APK with the same package and signing certificate can update an earlier installation, and versionCode must increase. No compatibility with a previous certificate is claimed without comparing its fingerprint.

The automated publication workflow requires a pinned certificate SHA-256 and persistent keystore for either publication profile. Checksums and `verification.json` describe the actual uploaded artifact.

## This fork's release identity

CarPlay assets are taken from DiPlay `v0.2.21` with the repository owner's explicit confirmation of permission to use and distribute them. The source APK matched upstream's published checksum, and the extracted key matches its certificate. Assets and signing files remain outside Git; only authorized release APKs contain authentication assets.

This fork uses a new permanent signing certificate: `e2caa2c7dbdda62b118b54962c44569a60e44dbcb6fc83f9ba40b00747d3c8fc` (SHA-256). Updates within this fork retain it. APKs signed by DiPlay, original GeePlay or another distributor cannot be assumed to update in place.

No connected Android device was available during preparation, so installation, an actual CarPlay authentication handshake, wired/wireless sessions and the merged build's physical G636/G426 behavior remain unverified.
