# GeePlay 0.2.21-geely.3

GeePlay — независимый несертифицированный проект для Geely/ECARX.

## Исправление входа в QNX

- Штатный пароль подставляется автоматически по той же политике, что и в AtlasDim.
  Поле пароля можно оставить пустым. Ручное значение имеет приоритет для прошивок
  с изменённым паролем и не сохраняется.
- Учтены приглашения `Password` и `Password:`.
- Исходный QNX-дисплей выбирается по политике AtlasDim: G426_J1 — 2, остальные — 1.
  Каждый объект сохраняет собственный выбор дисплея и слоя.
- Значение стандартного входа подаётся при сборке; в публичный Git оно не помещается.
  Релизный APK проверяется на наличие автоматического входа.

## Сохранённые возможности .2

- QNX-компонент встроен; установленный AtlasDim не требуется.
- Карта и стрелки добавляются, размещаются и удаляются независимо. Порты 53281/53283.
- Видео CarPlay stream 111, SurfaceTexture/OpenGL, сохранение пропорций, ограниченная
  очередь кадров, RLE32 и отдельная диагностика QNX.
- Экспериментальная передача метаданных музыки для отдельно установленного GMediaProxy.
- Постоянное исключение BYD-меню и связанных разрешений из GeePlay.

Версия приложения: 0.2.21-geely.3, versionCode 7. Пакет и постоянный сертификат
GeePlay сохранены. CarPlay-авторизация включается из разрешённых внешних assets.

[Инструкция](https://github.com/lisindima/GeePlay/blob/geely/main/docs/CITYRAY-QNX.md).
Новые функции остаются экспериментальными. Базовый CarPlay ранее проверен на G636;
аппаратной проверки новых QNX-окон GeePlay на Cityray пока не было. Работа времени
и топлива через AtlasDim подтверждена пользователем и служит основанием для
переноса его штатных параметров подключения, но не заменяет проверку новой сборки.
